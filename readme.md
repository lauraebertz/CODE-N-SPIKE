# CODE N SPIKE

## Descrição

CODE N SPIKE é um jogo de vôlei desenvolvido em HTML, CSS e JavaScript utilizando Phaser.

Dois jogadores disputam uma partida utilizando o mesmo teclado. O objetivo é chegar a 15 pontos primeiro. Cada lado pode realizar até 3 toques antes de enviar a bola para o adversário.
Durante a partida também aparecem estrelas colecionáveis, que podem ser utilizadas para desbloquear diferentes bolas.

## Controles

Jogador 1

A - mover para a esquerda  
D - mover para a direita  
W - pular  
S - peixinho  
Q - defender ou levantar  
E - sacar, atacar ou bloquear  

Jogador 2

Seta esquerda - mover para a esquerda  
Seta direita - mover para a direita  
Seta para cima - pular  
Seta para baixo - peixinho  
SHIFT - defender ou levantar  
ENTER - sacar, atacar ou bloquear  

ESC - voltar ao menu

## Requisitos

Navegador atualizado com suporte a HTML5 e JavaScript.

Recomendado: Google Chrome, Microsoft Edge ou Mozilla Firefox.

É necessária conexão com a internet para carregar o Phaser pelo CDN.
